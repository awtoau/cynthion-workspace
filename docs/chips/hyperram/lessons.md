# HyperRAM lessons from the old stack

Harvest of the deleted HyperRAM stack (tag `hyperram-old-last` = `220f514`; removed at `ebf4062` / `c153e65`, DQS at tag `dqs-last` / `c3388ef`) for the clean-room baseline ([sequential-baseline.md](sequential-baseline.md), [#581](https://github.com/awtoau/cynthion-workspace/issues/581)) and the no-CPU test image ([#591](https://github.com/awtoau/cynthion-workspace/issues/591)).

- Facts and test methods only; no design is carried over (clean-room rule, Dan, 2026-11-03).
- Old sources read with `git show hyperram-old-last:<path>`: `docs/chips/hyperram/*`, `scripts/hyperram/*`, `gateware/probes/hyperram/*`, `gateware/soc/peripherals/hyperram_*`.
- Old throughput figures before 2026-08-06 are void per the old docs; most DQS-era figures are void too (edge clock on fabric before `7d88981`, BURSTDET never settled). None are carried here.
- Verdict per item against the baseline at gateware `1d272c9`: **true** (still holds), **superseded**, **disproved**, **open**.
- Harvested 2026-11-03.
