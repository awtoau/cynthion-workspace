# Winbond W956A8MBYA (HyperRAM)

Source: `~/vendors/winbond/W956x8MBYA_A01-006.pdf` (rev A01-006, 2022-07-29). Section numbers below are that revision's.

## Part
- W956A8MBYA6I on Cynthion r1.4: 64 Mbit = 8 MiB, x8 HyperBus, 24-ball TFBGA.
- 3.0 V part: VCC/VCCQ 2.7-3.6 V (s11.3.1).
- Speed grade 6I = 166 MHz (Table 22, tCK min 6 ns). The schematic approves the 5I (200 MHz) as a substitute. Rev A01-006 dropped the 6I part number from the ordering table (revision history); the 166 MHz specifications stay.
- Pin rate 2 bytes per CK (DDR, 8 data lines; s6.1).
- Array: 9 column + 13 row address bits = 2^22 16-bit words; 512 words per row, 8192 rows (s8.1.1).

## Registers (s9.1 Table 5; CA word address)
| reg | addr | access | default |
|---|---|---|---|
| ID0 | 0x0 | r | 0x0c86 (s9.3 Table 6: 13 row bits, 9 column bits, manufacturer 0110b Winbond) |
| ID1 | 0x1 | r | 0x0001 (Table 7: HyperRAM 2.0) |
| CR0 | 0x800 | rw | 0x8F2F |
| CR1 | 0x801 | rw | 0xFFC1 |

- Register write: zero latency, single word, host does not drive RWDS (s7.4, s9.2).
- Register read: ordinary read with 1x or 2x latency (s9.2).

## CR0 0x8F2F (s9.4 Table 8)
- [15] 1 normal operation (0 = deep power down).
- [14:12] 000 drive strength 34 ohm (s9.4.5).
- [11:8] reserved, write 1.
- [7:4] 0010 initial latency 7 clocks, rated to 200 MHz; 0001 = 6 clocks to 166 MHz, 0000 = 5 clocks to 133 MHz.
- [3] 1 fixed latency: always 2x initial = 14 clocks (s9.4.4).
- [2] 1 legacy wrapped burst; [1:0] 11 = 32-byte wrap.

## CR1 0xFFC1 (s9.5 Table 11)
- [6] 1 single-ended CK; 0 = differential CK/CK#.
- [5] 0 normal (1 = hybrid sleep); [4:2] 000 full-array refresh.
- [1:0] 01 = tCSM 4 us; read only.

## tCSM (s9.5.4 Table 12, s12.3.2)
- CS# max low time 4 us at TCASE < 85 C (64 ms refresh / 8192 rows, halved).
- Above 85 C: 1 us in Winbond's Verilog model `Config-AC.v` (`` `define LA_85C ``; `sources/README.md`). Not in A01-006 (Table 12 has only the < 85 C row); the HyperRAM application note s6.5.7 lists CR1 `10b` (1 us) only for 256 Mb and later parts.
- Host must end every transaction before tCSM.
